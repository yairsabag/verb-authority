# Presentation assets

Upload [`social-preview.jpg`](social-preview.jpg) through the repository's
**Settings → General → Social preview** control. It is 1280 × 640 pixels and
kept below GitHub's 1 MB upload limit.

`social-preview-legacy.png` is retained only to preserve the history of the
earlier artwork. It contains retired messaging and must not be used as the
current repository preview.
